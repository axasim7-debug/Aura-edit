# 03 — جلب اللقطات (Clip Sourcing)

> اللقطة الرديئة لا يُنقذها أي مؤثر. **الجودة + اختيار اللحظة الصحيحة = نصف الإيديت.**

## 1. من أين يجلب المحررون اللقطات؟
### أ) Scenepacks (حزم مشاهد جاهزة) — الأكثر شيوعاً
- **ما هي**: مجلد لقطات مقطّعة مسبقاً لشخصية/فيلم (غالباً 1080p أو 4K، بلا ترجمة ولا شعار)، تُشارك عبر Google Drive / MEGA.
- **أين**:
  - **YouTube**: ابحث `"<اسم الشخصية> scenepack"` أو `"<movie> scene pack 4k"` أو `"<character> twixtor"` — الرابط في الوصف.
  - **Discord / Telegram**: سيرفرات المحررين (بعضها مجاني، بعضها مدفوع للـ 4K).
  - **Reddit**: r/AMV، r/AMVs، r/EditShare، r/Editors.
  - **مواقع مخصصة** (مجانية/مدفوعة): مثل ScenePacks.net، EditorsVault، twixtorclips.com، motionvault.space وغيرها. **احذر الإعلانات والتحويلات المريبة وافحص الملفات**.
  - **أنمي**: قنوات إيديت الأنمي، SakugaBooru (للقطات الأنيميشن القوية)، مجلدات GDrive مشتركة.
- **احرص على**: الدقة الفعلية (ليست upscale سيئ)، حجم الملف (bitrate عالٍ)، ثبات معدل الفريمات، **بلا ترجمة ولا شعار**.

### ب) القص بنفسك (أعلى جودة وتحكم)
- **المصدر الأفضل**: Blu-ray / WEB-DL (ملفات عالية الـ bitrate) — أعلى بكثير من فيديو YouTube.
- **من YouTube** (تريلرات، مقاطع رسمية، مباريات): أداة `yt-dlp`:
  ```bash
  # أفضل فيديو + صوت، دمج mp4
  yt-dlp -f "bv*[height<=2160]+ba/b" --merge-output-format mp4 "<URL>"
  # جزء محدد فقط (من 1:23 إلى 1:31)
  yt-dlp -f "bv*+ba/b" --download-sections "*00:01:23-00:01:31" "<URL>"
  ```
- **التسجيل من الشاشة**: OBS (آخر حل — جودة أقل، ومنصات البث تحجب التسجيل غالباً).
- **رياضة**: حسابات الدوريات/الأندية الرسمية، ملخصات عالية الجودة، "4K tunnel / walkout" clips.
- **قص بدون إعادة ترميز** (سريع، بدون فقد):
  ```bash
  ffmpeg -ss 00:12:03.5 -to 00:12:09.0 -i movie.mkv -c copy clip.mkv   # سريع لكن يقص على keyframes
  ffmpeg -ss 00:12:03.5 -to 00:12:09.0 -i movie.mkv -c:v libx264 -crf 14 -preset slow -an clip.mp4  # دقيق
  ```

### ج) لقطات أصلية (تصويرك)
- صوّر **60fps** (أو 120fps للسلو موشن)، إضاءة جيدة (الدرجة الداكنة تحتاج تفاصيل)، حركات جريئة: مشي واثق، كشف سيارة، رفع أثقال، نظرة للكاميرا.

### د) AI
- أدوات توليد الفيديو تُستخدم لصنع لقطات "أورا" غير موجودة (مثلاً أنمي لاعبي كرة). قاعدة: **حركة كاميرا واحدة لكل لقطة** (whip pan أو crash zoom) لتقليل التشوه، ثم الربط في المونتاج.

## 2. Raw vs Twixtor vs Upscaled vs Interpolated
| النوع | ما هو | متى تستخدمه |
|------|------|------|
| **Raw** | لقطة أصلية بلا معالجة | الأساس دائماً |
| **Twixtor** | لقطة مبطأة بإضافة إطارات (optical flow) من plugin Twixtor (RE:Vision) | السلو موشن الناعم جداً (velocity) بدون تقطيع |
| **Upscaled** | رُفعت دقتها (Topaz Video AI / Real-ESRGAN / waifu2x للأنمي) | مصدر ضعيف الدقة |
| **Interpolated 60fps** | إطارات وسيطة (RIFE / Flowframes / Topaz) | نعومة عامة، وتبطيء |

> **السلو موشن يحتاج إطارات أكثر من الإخراج**: تبطيء 5× عند 24fps يحتاج ~120fps مصدر. بدون ذلك ستتقطع اللقطة ⇐ استخدم Twixtor / RIFE أو Optical Flow (Premiere/DaVinci) أو "Smooth slow-mo" في CapCut.
> **الأنمي**: حذار — الأنمي يُرسم "on twos/threes" (إطار مكرر)، والاستيفاء قد يصنع تشوهات على الخطوط. RIFE مع إزالة الإطارات المكررة (dedup) أولاً أفضل. أحياناً التقطّع (choppy) **مرغوب** في الأنمي.

## 3. اختيار "اللقطة الصحيحة" — معايير الأورا
لكل لقطة مرشحة اسأل:
1. **هل فيها "لحظة"؟** نظرة/ابتسامة/التفاتة/حركة حاسمة (انظر قائمة اللحظات في 01).
2. **هل الوجه/الشخصية واضح؟** كلوز-أب ومتوسط قريب أفضل للشورتس العمودي.
3. **هل هي قابلة للقص العمودي 9:16؟** الشخصية يجب أن تكون في منطقة يمكن قصها (أو ستحتاج reframe متحرك).
4. **هل الحركة داخلها تتماشى مع الضربة؟** (حركة رأس، رمش، قبضة يد، سقوط شيء = نقطة مزامنة طبيعية).
5. **نظافة**: بلا ترجمة، بلا شعار، بلا أشرطة سوداء مزعجة، bitrate جيد.
6. **الإضاءة/اللون**: هل ستصمد مع تدريج داكن؟

### أنواع اللقطات المطلوبة لكل إيديت (shot list)
| الدور | العدد | الوصف |
|------|------|------|
| **Hook/Opener** | 1 | لقطة غامضة أو قوية للثانية الأولى (ظهر، ظل، عين، أو أقوى لقطة مُعاينة) |
| **Build** | 2–4 | لقطات هادئة/بطيئة: مشي، تفاصيل (يد، عين، ساعة)، أجواء |
| **Drop shot** | 1 | **الأقوى**: نظرة للكاميرا / smirk / التفاتة |
| **Peak/Hype** | 4–12 | لقطات قصيرة على الضربات: حركات، أكشن، ردود فعل، زوايا مختلفة |
| **Detail inserts** | 2–4 | عين، يد، سلاح، ابتسامة — للقطعات السريعة على cowbell/hats |
| **Reaction** | 1–2 | الآخرون مذهولون/خائفون (يثبت الأورا) |
| **Outro/Loop** | 1 | تجميد / مشي بعيداً / قطع لأسود / لقطة تتصل بأول فريم |

**نصيحة**: اجمع **3 أضعاف** اللقطات التي تحتاجها، ثم اختر الأفضل.

## 4. تنظيم المكتبة (لاستخدام Remotion لاحقاً)
```
library/
  <character_slug>/
    raw/        # المصدر الأصلي
    clips/      # مقطّعة: <slug>_<nn>_<tag>.mp4  مثال: bateman_07_smirk.mp4
    interp/     # نسخ 60/120fps مستوفاة
    masks/      # ماسكات (alpha) للنص-خلف-الشخص
    meta.json   # وصف كل لقطة
```
مثال `meta.json` (يغذّي اختيار اللقطات آلياً):
```json
[
  {"file": "clips/bateman_07_smirk.mp4", "tags": ["smirk","closeup","eye-contact"],
   "role": ["drop"], "energy": 0.9, "fps": 23.976, "duration": 3.2,
   "focus": {"x": 0.52, "y": 0.38}, "momentAt": 1.4}
]
```
- `focus`: مركز الوجه (للقص العمودي 9:16 والزوم).
- `momentAt`: الثانية التي تحدث فيها "اللحظة" (لمحاذاتها مع الضربة).

## 5. القانون (باختصار — التفاصيل في 12)
- لقطات الأفلام/المسلسلات/المباريات **محمية بحقوق النشر**. مواقع الـ scenepack تدّعي "fair use" — هذا ادعاؤها، ليس حكماً قانونياً.
- التحويل الإبداعي (transformative) يقلل المخاطر لكنه لا يلغيها. توقّع Content ID claims، خصوصاً على يوتيوب.
